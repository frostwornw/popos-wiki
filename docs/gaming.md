# Оптимизация игр в Pop!_OS 🎮

Pop!_OS считается одним из лучших дистрибутивов для гейминга благодаря встроенным драйверам NVIDIA «из коробки». Вот как выжать максимум производительности из вашей системы.

## 🚀 Включение GameMode

В систему встроен планировщик **Feral GameMode**, который автоматически оптимизирует работу процессора и видеокарты во время запуска игр.

Чтобы игра в Steam запускалась с ним, нажмите по ней правой кнопкой мыши -> **Свойства** -> в строку **Параметры запуска** вставьте:
```bash
gamemoderun %command%
```

## 🏎 Переключение графики на ноутбуках

Если у вас игровой ноутбук с гибридной графикой (Intel/AMD + NVIDIA), вы можете переключать режимы прямо из правого верхнего угла системного меню COSMIC:
* **Integrated Graphics** — работает только встроенный чип (для экономии батареи).
* **Discrete Graphics** — всё работает на мощной видеокарте NVIDIA.
* **Hybrid Graphics** — система сама решает, что запускать (рекомендуется).
